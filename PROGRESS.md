## Implementation Decisions Made During Development

- `.dproj` not created by CC — must be generated by Delphi IDE to ensure correct MSBuild XML structure and version info. CC created `.dpr`, `.pas`, and `.dfm` only.
- `LICENCE` file uses the name without extension (no `.txt`) — standard convention for Codeberg/GitHub repositories.
- `IsValidUnitName` in `uProjectParser.pas` uses `CharInSet` instead of `Char.IsLetterOrDigit` — the helper method caused cascading compile errors; `CharInSet` is more reliable.
- `TryStrToFloat` in `uRTLScanner.pas` requires explicit `Double` type declaration and `TFormatSettings` parameter — `var NumVal := 0.0` type inference caused overload resolution failure.
- `uMainForm.pas` threading: `TTask.Run` with nested anonymous methods capturing variables fails in Delphi 64-bit compiler. Replaced with proper `TThread` descendants (`TSBOMGenerateThread`, `TSBOMValidateThread`) using `Synchronize` for UI updates.
- `TProc<TLogLevel, string>` anonymous method parameters must not use `const` — `TProc<T1, T2>` signature is `procedure(Arg1: T1; Arg2: T2)` without `const`, and the compiler rejects the mismatch.
- `SelectDirectory` calls require `Vcl.FileCtrl.SelectDirectory` (fully qualified) and `var Dir: string` (explicit type, not inferred) for correct overload resolution.
