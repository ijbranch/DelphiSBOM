## Implementation Decisions Made During Development

- `.dproj` not created by CC — must be generated by Delphi IDE to ensure correct MSBuild XML structure and version info.
- `LICENCE` file uses the name without extension — standard Codeberg/GitHub convention.
- `IsValidUnitName` uses `CharInSet` instead of `Char.IsLetterOrDigit` — helper method caused cascading compile errors.
- `TryStrToFloat` requires explicit `Double` type declaration and `TFormatSettings` parameter.
- Threading: `TTask.Run` with nested anonymous methods fails in Delphi 64-bit. Replaced with `TThread` descendants using `Synchronize`.
- `TProc<TLogLevel, string>` anonymous method parameters must not use `const`.
- `SelectDirectory` requires `Vcl.FileCtrl.SelectDirectory` (fully qualified) and explicit `var Dir: string`.
- `USE_SYNEDIT` conditional NOT committed in `.dproj` — developers add locally if SynEdit available.
- Own-code detection: units with `in` file references in .dpr + `own_code_units` array in `components.json` + auto-detection from sibling project directories.
- Library naming priority: .dpk package name → non-generic ancestor directory → directory name.
- Nested library directories merged (e.g. EurekaLog Source + Extras → single entry).
- IDE environment variables read from registry for path resolution (STYLEDCOMPDIR, etc.).
