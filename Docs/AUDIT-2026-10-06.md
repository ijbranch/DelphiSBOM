## Verified sound

- CycloneDX core: `bomFormat`, `specVersion`, `serialNumber` (`urn:uuid`, lower case, no braces), numeric `version`,
  1.5 `metadata.tools.components` shape, supplier `url` array, `Commercial` as `license.name`.
- JSON ownership in `Load` / `LoadEvidence`; exact-before-prefix, first-match-wins as documented.
- Threading design: workers never touch VCL directly, no `WaitFor` on the main thread (no `Synchronize` deadlock),
  close blocked while processing, options passed as a copied record.
- No leaks in the form, dialogs, engine or loaders on normal paths; DFM and code event wiring agree;
  `AppDPIAwarenessMode=unaware` in both configs; INI folder created before writing.
